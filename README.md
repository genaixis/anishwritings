# anishwritings.com

Marketing site for **Anish Writings**, publisher of *Janaki Chenthaku Ram* (జానకి చెంతకు రామ్) by Anish Babu Kosuru — based on [Flipkart listing](https://www.flipkart.com/janaki-chenthaku-ram/p/itmd5710fc813fd5?pid=9789359969350).

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
```

Deploy the `dist/` folder to your host for **anishwritings.com**.

## Stack

- Vite + React + TypeScript
- Framer Motion (scroll reveals, 3D book tilt, loader)
- Canvas ambient particles

## Customize

Edit `src/data/book.ts` for copy, prices, and buy links.
